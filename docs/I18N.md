# Internacionalización (i18n)

## Estado actual

- **UI chrome**: español e inglés (`js/locales/es.js`, `js/locales/en.js`)
- **Contenido**: lecciones, meditaciones, citas y copy educativo en español

## Uso

```js
import { t, setLocale, initI18n } from '/js/i18n.js'

initI18n() // lee settings.locale
setLocale('en')
const label = t('nav.home')
```

## Añadir cadenas

1. Agrega la clave en `js/locales/es.js` y `js/locales/en.js`
2. Usa `t('seccion.clave')` en el componente
3. Si afecta navegación, llama `remountNav()` tras cambiar idioma (ya lo hace `setLocale`)

## Configuración del usuario

**Ajustes → General → Idioma**

El atributo `lang` del `<html>` se actualiza automáticamente.
